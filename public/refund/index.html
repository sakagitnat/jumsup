นโยบายการยกเลิกและการคืนเงิน (Refund & Cancellation Policy)

มีผลตั้งแต่วันที่ 3 กันยายน 2026 · นโยบายนี้เป็นข้อกำหนดผลิตภัณฑ์ ไม่ใช่คำแนะนำทางกฎหมาย

สินค้าที่ครอบคลุม

Jumsup Pro เป็นสมาชิกแบบชำระเงินรายเดือนหรือรายปี ต่ออายุอัตโนมัติ ราคาและรอบเรียกเก็บจะแสดงก่อนชำระเงินทุกครั้ง การชำระเงินดำเนินการผ่าน Stripe

การยกเลิกสมาชิก

  • ยกเลิกได้ทุกเมื่อจาก โปรไฟล์ → การชำระเงินและคืนเงิน (Stripe Billing Portal)
  • เมื่อยกเลิก สมาชิกยังใช้งานได้จนสิ้นสุดรอบที่ชำระไว้แล้ว จากนั้นจะไม่ต่ออายุและไม่มีการเรียกเก็บอีก
  • การยกเลิกเพียงอย่างเดียวไม่ใช่การขอคืนเงิน

เงื่อนไขการคืนเงิน

  • ขอคืนเงินได้ภายใน 7 วัน นับจากวันที่เรียกเก็บ หากยังไม่ได้ใช้สิทธิ Pro อย่างมีนัยสำคัญในรอบนั้น
  • การต่ออายุอัตโนมัติ: หากขอภายใน 7 วันหลังต่ออายุและยังไม่ได้ใช้สิทธิ Pro ในรอบใหม่ พิจารณาคืนเต็มจำนวน
  • หลังจากนั้น โดยทั่วไปจะไม่คืนเงินสำหรับรอบที่ใช้ไปแล้ว เว้นแต่กฎหมายกำหนด หรือกรณีระบบมีข้อผิดพลาดที่ทำให้ใช้บริการไม่ได้
  • ไม่มีการคืนเงินบางส่วนตามสัดส่วนวันที่เหลือ เว้นแต่ Jumsup พิจารณาเป็นรายกรณี
  • โดยทั่วไปคืนเงินได้ 1 ครั้งต่อบัญชี คำขอครั้งต่อไปจากบัญชีเดิม รวมถึงการสมัคร–ขอคืน–สมัครใหม่ซ้ำ ๆ Jumsup อาจปฏิเสธได้

วิธีขอคืนเงิน

  1. ไปที่ โปรไฟล์ → การชำระเงินและคืนเงิน → "ขอคืนเงิน" พร้อมระบุเหตุผล
  2. ผู้ดูแลตรวจสอบคำขอ การคืนเงินไม่เป็นอัตโนมัติ
  3. เมื่ออนุมัติ เงินจะคืนผ่าน Stripe ไปยังช่องทางชำระเงินเดิม
  4. ระยะเวลาที่เงินเข้าบัญชีขึ้นกับ Stripe และธนาคารผู้ออกบัตร (โดยทั่วไป 5–10 วันทำการ) ซึ่งอยู่นอกเหนือการควบคุมของ Jumsup

ผลของการคืนเงิน

  • การคืนเงินเต็มจำนวนสามารถยกเลิกสมาชิกที่เกี่ยวข้องทันที หากผู้ใช้เลือกตัวเลือกนั้น การคืนบางส่วนไม่ยกเลิกสมาชิกโดยอัตโนมัติ
  • หากการชำระเงินที่ถูกคืนเป็นการชำระครั้งแรกที่ทำให้ได้สิทธิโบนัสจากการแนะนำเพื่อน สิทธิ Pro โบนัสนั้นจะถูกเพิกถอน
  • รายการคืนเงินและข้อโต้แย้งทั้งหมดถูกบันทึกไว้ในระบบ

Gift Code และโปรโมชัน

สิทธิ Pro ที่ได้จาก Gift Code หรือโปรโมชันไม่มีมูลค่าเป็นเงินสดและคืนเป็นเงินไม่ได้

ข้อโต้แย้งการชำระเงิน (Chargeback)

หากพบปัญหาการเรียกเก็บ โปรดติดต่อเราก่อนเปิดข้อโต้แย้งกับธนาคาร เรามักแก้ไขให้ได้เร็วกว่า
